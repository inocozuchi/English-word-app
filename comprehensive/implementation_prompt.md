# Claude Code 実装指示 — EIGO LOOP 総合英語モード

対象リポジトリ: inocozuchi/English-word-app。ルートの comprehensive/ に教材一式を配置済みであることを確認してから作業する。未配置なら作業を止めて知らせる。既存コードを調査し、専用ブランチ feature/comprehensive-course で実装する。main への直接 push、既存履歴の削除、外部AI/API導入は禁止。既存の語源・チャンク等のモード、保存データ、バックアップ互換性を守る。最新のコードを正とし、以下のパスやAPI名は実在確認してから使用する。

## 最優先の仕様
- modeId は comprehensive。日本語UI。Day1〜60は全日収録済み。Day0/60診断は別データ。通常5010問、診断60問、基本1064項目、図解344グループ。目標数ではなく実ファイルの件数を正とする。
- comprehensive_course.json を通常教材の正本、curriculum.json を日程、learning_policy.json を出題負荷、quality_report.json を重複抑制の正本とする。専用 reference は表示・補助練習に使い、同じ問題を二重登録しない。旧段階の記述と矛盾する場合はこの最終指示を優先する。
- ワンボタン開始/再開、既定60分、20/60/90/120分の変更は任意。学習時間は目安で強制終了なし。前日・期限復習→単語・熟語→チャンク→文法→英作文→言い換え→音声→会話→読解→混合→再挑戦。空の段階は飛ばす。全候補を必須にしない。短縮時に未出題の必須教材を消化済みにしない。未学習の必須教材は次回以降に繰り越し、日程進行と習熟度は別管理。休んだ日も復習を一括強制しない。
- 各回答でキュー、カーソル、採点、選択肢順、分岐ノードを保存。再開で二重記録しない。既存SRSと統合し、itemIds が空なら問題IDを使用。0/1/3/7/14/30日を基準に調整。0は当日再試行。重複別名は同一セッションで抑制し、IDを削除しない。認識・想起・活用・定着を区別し、ヒント・自己採点・回答時間も別記録。
- 全7種の通常問題 kind を実装する。複数許容解答、大小文字・空白・文末句読点・明示的短縮形を慎重に正規化。否定・時制・単複を無視しない。自由回答は模範解答と自己採点を提供し、自動正解と区別する。音声問題では答えや原稿を先に見せない。
- TTSは Web Speech API、en-NZ→en-GB→他の英語、速度0.75/1/1.25、停止・再生回数・voiceschanged対応。端末依存、音声不可は別記録し文字学習へ振替。発音自動採点なし。分岐会話は定型ノード方式で聞き返しも成功経路とする。読解は架空文書。
- 図解は visual_reference.json の実際の全typeを列挙して共通レンダラーを作る。色だけに依存せず、文字ラベル・ダークモード・スマホ幅・アクセシビリティに対応。カナや訳は切替。IPA等は存在時のみ。詳細解説は折りたたむ。答えを含む図は出題後に表示。
- Day0/60各30問は通常学習から隔離し、途中保存、終了まで答え非表示、音声不可・スキップ・自己採点を別集計。比較は同条件・同分野のみ。TOEIC換算や進級判定をしない。週次復習は既存日程から混合抽出し、独立した標準化試験とは呼ばない。
- 辞典検索、お気に入り、弱点、60日ロードマップ、学習レポートのコピーを副導線にする。自由会話・自由作文はChatGPTで練習する想定。既存のChatGPT定期配信は変更しない。PWAキャッシュ、オフライン教材、旧バックアップ復元を保護する。音声のオフライン動作は保証しない。

## 作業順序と完了条件
1. git status、既存モード登録、store/storage、SRS、音声、PWA、テストを調査。変更計画を示す。ユーザーの未コミット変更を上書きしない。
2. データローダー・型・Schema検証・参照検査を追加。manifest.json のハッシュと件数を確認。未対応形式や不正データは明示する。
3. 学習キュー・保存/再開・採点・復習を実装し、単体テストを作る。
4. 既存UIに総合モードを登録し、図解、音声、会話、読解、診断、辞典を段階的に統合する。各段階で既存モードを回帰確認する。
5. npm run check、npm test、npm run build、および既存データ検証コマンドを実行する。存在しないコマンドは捏造しない。日付変更、タイムゾーン、20分短縮、休止復帰、二重記録、音声不可、Day60後、旧バックアップ、PWA更新、狭い画面、答え漏洩をテストする。
6. 変更ファイル、実装済み/未実装、テスト結果、既知の問題、iOS実機確認手順を報告する。実機未検証なら明記。mainへのマージ・公開はユーザー確認後。

教材の全件言語校閲、許容解答の網羅、音声品質、学習効果の実証は未完了。問題を見つけた場合は安定IDを維持し、変更理由を記録する。教材量の不足を架空データで埋めない。
