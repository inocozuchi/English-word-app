# 複数の端末で使う（Firebase の同期）の準備

EIGO LOOP の学習記録を、iPhone・iPad・パソコンで同じにするための置き場を、Google の無料サービス **Firebase（Cloud Firestore）** に作ります。
置き場を作らなくても、アプリは今までどおり各端末の中だけで動きます。

## 1. Firebase で置き場を作る（1回だけ・無料の Spark プラン）

1. https://console.firebase.google.com/ を開き、「プロジェクトを作成」。名前は `eigo-loop` など（Google アナリティクスはオフでよい）。
2. 左の「構築」→「Firestore Database」→「データベースを作成」。
   - ロケーション: `asia-northeast1`（東京）
   - 「本番環境モード」で開始
3. 「ルール」のタブを開き、このリポジトリの **`firestore.rules`** の中身をそのまま貼って「公開」。
   （Firebase CLI があれば `firebase deploy --only firestore:rules --project <プロジェクトID>` でも同じ）
4. 歯車 →「プロジェクトの設定」→「マイアプリ」→ ウェブ（`</>`）でアプリを登録（Hosting は不要）。
   表示される `const firebaseConfig = { … };` をコピーする。

> Web 用の `apiKey` は公開してよい識別子です（守りは `firestore.rules`）。認証（ログイン）は使いません。

## 2. アプリに接続設定を入れる（どちらか）

- **アプリで貼る（すぐ使える）**: 設定 →「複数の端末で使う」に `firebaseConfig` を貼り、「〇〇 を使う」。端末ごとに1回。
- **リポジトリに入れる（全端末で不要に）**: `src/sync/config.ts` の `null` を `firebaseConfig` のオブジェクトに置き換えてビルド・公開する。

## 3. 端末をつなぐ

1. 1台目: 設定 →「複数の端末で使う」→「同期を始める」。**同期コード**（`XXXXX-XXXXX-XXXXX-XXXXX`）が出る。「コピー」できる。
2. ほかの端末: 「コードを入れる」→ 同じコード →「このコードで同期」。
   - それぞれの端末の記録はまとめられ、どちらも消えません。
3. 以後は自動: 起動したとき・アプリに戻ったとき・答えてから数秒後・アプリを離れるとき・開いている間は5分ごと。
   クイズ・学習の途中は同期せず、終わってから。通信できないときは何もしません（つながったら同期）。

**同期コードはパスワードと同じです。** 知っている端末は記録を読み書きできます。人に見せないでください。
やめるときは「この端末の同期をやめる」（記録はその端末に残ります）。

## 何が同期されるか

| 同期する | この端末だけ |
| --- | --- |
| 全モードの学習記録（間隔反復・日ごとの回答数・復習リスト・苦手・反射の記録・総合英語の進み具合など） | 音声を使う・文字を入力する問題・自己採点の問題（端末ごとの状況） |
| 設定（問題数・今のモード・各モードの出題範囲・秒数） | テーマ・触覚 |
| 自由英単語の単語（両方の端末の単語を合わせる。消した単語は消えたまま） | 中断したクイズ |
| 総合英語の今日のセッション（新しい方） | |
| 「この問題を報告」 | |

### まとめ方（2台で別々に学習したとき）
- 問題ごとに **最後に答えた方** の記録を使う。日ごとの回答数は多い方。
- 復習リストは両方を合わせ、片方でその後に正解を続けて外れたものは外す。
- 設定・セッションは新しく変えた方。

## 置き場の中身と無料枠

- `eigo/{同期コードの SHA-256}` … 目次（保存キーごとの中身の印・時刻・分けた数、版）
- `eigo/{…}/c/{保存キー~印~番号}` … 中身（gzip。700KB ごとに分ける）
- 変わった保存キーだけを送るので、1回の同期は「目次の読み1回」＋変わった分だけ。
  無料枠（1日 読み 50,000・書き 20,000・保存 1GB）を個人で使い切ることはまずありません。

## 試験

- `npm test` … まとめ方と手順（メモリの置き場で2台・同時に書いたとき・消したとき）
- `npm run test:firebase` … Firestore エミュレーター（要 Java）で、本物の置き場のコード・`firestore.rules`・アプリの画面で2台の同期
  （初回は `cd tests/firebase && npm i`。`npm run build` のあとに）
