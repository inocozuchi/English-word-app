# 英語イメージリンク クイズデータ

教科書「英語イメージリンク 完全版テキスト」（全187章）から作った問題集です。英語クイズアプリの「イメージリンクモード」用です。

## 構成
- `index.json` … 部・章の一覧と、章ごとの問題数、教科書のページ番号
- `questions/part1.json 〜 part4.json` … 問題本体（配列）。部ごとに分割
- `figures/` … イメージ図のSVG（`fig_001.svg` など。`prep_*.svg` は文字なしの前置詞アイコン）
- `figures.json` … 図の一覧（図ID・ファイル・キャプション・出てくる章）
- `validate.py` … データの整合性チェック（`python3 validate.py`）

部：1＝やり直し中学英語（第1〜59章）／2＝基本動詞と基本単語（第60〜103章）／3＝基本単語と違い系（第104〜124章）／4＝文法の詳細（第125〜187章）

## 共通フィールド
| フィールド | 意味 |
|---|---|
| `id` | 問題ID（再生成しても同じ内容なら同じ値） |
| `type` | 上の表のtype |
| `part` / `chapter` / `chapter_title` | 部・章番号（本書の通し番号）・章タイトル |
| `ref_page_a5` | 教科書（A5閲覧用PDF）のページ番号 |
| `section` | 章の中の節の見出し |
| `difficulty` | `easy`（5語以下）／`normal`／`hard`（10語以上）。例文の語数で決めた目安 |
| `tags` | 絞り込み用のタグ |
| `question` | 出題文 |
| `prompt_en` / `prompt_ja` | 問題に表示する英文・日本語 |
| `answer` | 正解 |
| `distractors` | 誤答の候補（3〜5個）。**アプリ側で3つ選び、正解と混ぜてシャッフルする** |
| `explanation` | 解説（教科書の「ポイント」欄）。あれば答え合わせで表示 |
| `speak` | 読み上げ用の英文（音声合成に渡す） |
| `confidence` / `note` | `medium` の問題には、他の選択肢も成立しうる旨の注意（cloze のみ） |

## type ごとの追加フィールド
- `order`：`tokens`（並べ替える語句、シャッフル済み）、`answer`（正しい英文）
- `translate`：`answer`（模範解答）。正誤は自己採点
- `exercise`：`answer_mode`＝`short`（短い答えを入力。空白・大文字小文字・文末記号を無視して比較）／`self`（自己採点）
- `fig_caption`：`figure`（SVGの相対パス）、`figure_id`
- `fig_choose`：`answer_figure`、`distractor_figures`（3つ）
- `prep_icon`：`figure`、またはfigure選択型（`answer_figure`＋`distractor_figures`）
- `flashcard`：`question`が表面、`answer`が裏面（改行区切り）

## 注意点
- 例文・ポイント・図はすべて教科書からの引用で、誤答はほかの例文・表から機械的に選んでいます。誤答のほうが正しく見える問題が少数あり得るため、アプリに「この問題を報告」ボタンを付けてください。
- `en2point` の選択肢は長めの日本語です。スマートフォンでは折り返して表示してください。
- 図のSVGは日本語フォント（Noto Sans CJK JP など）で描かれています。表示環境にない場合は、システムの日本語フォントで代替されます。
